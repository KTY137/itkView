# itkView v0.1.1

This patch release separates missing production evidence from confirmed test
failures and improves dense module-detail layouts.

## Changes

- A required test that is overdue but has no mirrored result is now shown as
  `Required tests missing` with a neutral question-mark marker. It no longer
  creates a red `Production hold` or critical card/row styling.
- A confirmed failed required test still creates the red `Production hold`.
- Current-stage missing tests remain normal work in progress and do not create
  either marker until their configured gate has been crossed.
- Expanded map-valued measurements, including metrology and wire-bonding data,
  use full-width responsive position/value grids. Long labels, keys and values
  wrap within their own cells instead of overlapping adjacent results.
- The desktop shell can use up to 1920 px, with more space assigned to the
  worksheet and run-detail column.
- Account and sign-out controls stay directly below the product header while
  long navigation menus scroll independently.
- Account now includes a browser-local appearance editor with system, light
  and dark themes plus copper, blue, teal and violet accent palettes.
- Manual component metadata sync and test-evidence sync are separate actions;
  a component sync no longer starts evidence implicitly.
- A browser-local lightweight evidence mode syncs module test evidence only
  and skips new attachment downloads. Existing mirrored evidence and files are
  preserved. Standard mode keeps the configured full evidence scope.

## Read-only boundary

The itkView boundary is unchanged: authoring, upload, staging, assembly, stage
moves and PDB writes remain unavailable in both the UI and server policy.

## Known limitations

- The Windows installer is not code-signed, so Windows SmartScreen may warn.
- A new installation still needs a mirror sync after personal PDB credentials
  are connected under **Account**.

## Installer integrity

The exact installer size and SHA-256 are recorded after the reproducible
release build.
